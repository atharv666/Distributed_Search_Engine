# Presentation Deck

Open `index.html` in a browser. It is a 12-slide, self-contained HTML/CSS/JavaScript presentation for the FA-1 distributed-search-engine project.

Navigation: Left/Right arrows, Space, Page Up/Down, Home/End, or the on-screen buttons. Slide URLs include a hash, so an individual slide can be revisited or shared.

The deck uses CSS-built diagrams rather than external images, so it runs without internet access and is easy to customize.
