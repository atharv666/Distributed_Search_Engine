Vector trace [C1, C2, C3, N1, N2, N3]

Each row is one event, in causal order. A vector has one counter per process, in the order shown above, for example [0, 0, 1, 0, 0, 0] means "C3 has done one event and nobody else has done anything yet". Pink entries changed at this event; the underlined entry is the process's own counter. Click a row (or a dot) to inspect it, click a second one to compare.
